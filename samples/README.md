# Sample renders

Committed example outputs, so they can be viewed on GitHub. `output/` is gitignored for everyday renders; these are the deliberate samples copied here. Every sample has Kokoro narration, sound cues, the parkour background (`background.dim` 0.2), and the bottom-anchored chat card. Each `.report.json` has the stage timings, validation warnings, QA summary, and API usage (zero).

The earlier plain full-screen versions of the first five are still in Git history (commit `014d2e2`).
